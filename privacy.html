AIこうしろうカンパニー（以下「当社」）は、自社のYouTubeチャンネルへ動画を予約投稿するための社内ツール（以下「本ツール」）で、YouTube API サービスを利用しています。本ツールの利用者は当社のみで、外部の方に提供するものではありません。本ポリシーは、本ツールが扱う情報について定めます。

1. 本ツールが使う情報

  • 当社のGoogleアカウントで許可した、当社のYouTubeチャンネルへの投稿・編集の権限（OAuth のアクセストークンと更新トークン）
  • 当社が作った動画・サムネイル・字幕と、そのタイトル・説明欄・タグ・公開予定時刻
  • 投稿した動画の ID と URL

当社以外の方の個人情報や、視聴者の情報は取得しません。

2. 使い道

当社のYouTubeチャンネルに、当社の動画を予約投稿し、サムネイル・字幕・再生リストを設定するためだけに使います。広告や分析、第三者への提供には使いません。

3. 保存と管理

トークンは当社のパソコンの中の、本人だけが読める場所に保存します。外部のサーバーには保存せず、第三者に共有・販売しません。

4. 権限の取り消し

本ツールへの権限は、Googleアカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」からいつでも取り消せます（https://myaccount.google.com/permissions）。取り消すと、保存したトークンは使えなくなります。

5. YouTube と Google について

本ツールは YouTube API サービスを利用しています。YouTube の利用には YouTube 利用規約（https://www.youtube.com/t/terms）が適用され、Google による情報の扱いは Google プライバシーポリシー（https://policies.google.com/privacy）に従います。

7. 削除

本ツールの利用をやめるとき、または権限を取り消したときは、保存したトークンを当社のパソコンから削除します。投稿した動画の削除は、YouTube Studio で行えます。

8. 改定

内容を変えるときは、このページで知らせます。
